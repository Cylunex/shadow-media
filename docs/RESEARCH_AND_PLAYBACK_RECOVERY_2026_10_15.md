## 2. 优先级与选择

| 顺序 | 方向 | 判断与边界 |
| --- | --- | --- |
| P0，本轮 | 普通视频失败恢复 | 每种网络来源都会遇到；能复用现有 Media3、鉴权隔离和进度逻辑；无需新服务或数据迁移 |
| P1 | 继续观看 + 下一集、混合库展示 | 需明确完成判定、下一集去重和跨账号作用域，建议单独交付 |
| P1 | 本地视频队列与目录连续播放 | 可借已有音频队列的“重复实例 ID”，但视频退出/结束语义需独立设计 |
| P2 | 解码器选择与字幕设置持久化 | 需要真实格式样本、轨道稳定身份和设备兼容矩阵；不直接把 ISO 专用 mpv 切给所有视频 |
| P2 | DLNA/远端播放 | 先设计控制权、进度与凭据可达性；不能把携带账号的临时地址直接广播 |

本轮不更新依赖版本，也不增加服务管理能力。重点补齐已有播放路径的恢复闭环。

## 3. 现状问题

1. `PlaybackRuntime` 对致命错误直接切下一候选；断网会消耗候选和一次 PlaybackInfo 刷新额度。
2. `ExternalPlaybackRuntime` 失败时只显示异常正文，缺少原位重试；有字幕时任何错误都先移除字幕。
3. 普通 Emby 播放的“重新解析”使用最初打开位置，重新创建播放器时默认自动播放。
4. 现有 HTTP 层已有短重试、302 重新回源和凭据隔离；再叠加无限定时器会放大 NAS/CDN 请求。
5. Feed 可复用预加载源，失败后继续取同一实例可能复用已经失败的加载状态。

## 4. 本轮实现

### 恢复状态与次数约束

`PlaybackRecovery` 独立于 Android UI，接受连接、前后台、播放意图和仅离线策略；只有可恢复错误进入自动流程。

```text
致命错误 → 分类
  ├─ 网络 / 超时 / 临时 HTTP / 直播窗口过期
  │    ├─ 暂停或后台 → 等待继续播放
  │    ├─ 无默认网络 → 等待连接恢复
  │    └─ 可播放 → 1 秒 / 3 秒退避 → 重新准备当前资源
  └─ 权限 / 资源缺失 / 格式 / 解码 / 未知 → 原有候选回退或明确错误提示

退出 → 注销网络回调 + 取消待恢复任务
```

- 每个 Runtime 最多两次应用级自动重试。READY、重复网络通知、切换候选均不重置额度；显式点击重试或新播放会话才重置。
- 已有 Media3 加载重试和 Emby HTTP 重试继续存在；这里的两次指应用级重新准备次数，不是总 HTTP 请求数。
- Emby 达到额度后继续原候选链及一次 PlaybackInfo 刷新。仅离线模式停止自动恢复，不继续消耗候选。
- 连接回调只唤醒已有待恢复错误；正常播放时切换网络不会主动打断视频。
- 暂停、睡眠定时、播放互斥或后台暂停都会撤销延迟任务，保留待恢复状态；重新播放后再安排。
- 应用级恢复重用播放器，读取重试时的当前位置与播放意图；保留速度及轨道参数。直播恢复到当前直播默认位置，点播保持位置。
- Feed 恢复绕开原预加载源，重新通过原来的同源凭据隔离客户端打开资源。

### 用户入口与故障说明

- 普通 Emby、HTTP 外部视频显示等待网络、等待播放、恢复中和失败提示；提供“从当前位置重试”。
- 本机文件支持同一手动重试入口，但不注册网络监听，不对文件权限/不存在/格式错误自动重试。
- 锁定或画中画时隐藏提示操作层；网络监听与恢复任务随播放器释放。
- Emby 手动重新解析向 ViewModel 传当前时间和 `playWhenReady`，避免退回原打开位置或把暂停改为播放。
- 错误正文按类别生成，只带必要 HTTP 状态或 Media3 错误码，不直接展示底层异常、URL 或服务器响应正文。
- 字幕回退只针对可归因于外挂字幕的 HTTP 请求失败或文本渲染错误；普通视频网络/解码失败不再无条件移除字幕。无法确认故障归属时保留字幕配置，显示失败供用户处理。

### 范围

自动恢复主要覆盖 Media3 明确标识的网络、超时、临时 HTTP 与直播窗口错误。SMB 仍使用同一路由和手动重试；
SMBJ 包装为通用 IO 的错误没有可靠分类时不猜测为可自动恢复。ISO/libmpv、后台音频和首次 PlaybackInfo 解析失败维持原逻辑。
长暂停后的主动刷新、外部 Provider 过期地址重新解析、用户自定义重试次数、按线路健康自动换源留待单独实现。
默认网络存在只表示可尝试访问，不保证 NAS 或远端主机一定可达；连接后仍失败会消耗有限额度并显示结果。

## 5. 验证

自动检查涵盖：断网等待与重连、暂停与后台门控、网络抖动、预算耗尽、READY 不重置预算、退出取消、仅离线开关、
手动操作取消旧任务、重复错误合并、字幕故障归属和 HTTP/文件/格式/解码错误分类。执行结果见本节末尾。

真机仍需验收：

1. HTTP 点播播放到中段后断网，错误出现后恢复 Wi-Fi，确认从中断位置恢复；仅局域网且没有公网连接的 NAS 同样验证。
2. 等待恢复时暂停、退到后台、切换音频或等待睡眠定时到期，再联网；确认没有意外出声。
3. 连续制造三次失败，确认停止自动重试；手动重试后重新允许有限恢复。
4. Emby 转码中断后恢复，确认绝对进度与 `StartTimeTicks`；暂停时点重新解析，确认新播放器仍暂停。
5. Feed 预加载命中后断网，恢复时确认重开资源；等待重试时切页/返回，确认旧页面不重新播放。
6. 直播离开滑动窗口后恢复到当前直播；点播保持进度和速度。
7. 带字幕视频分别制造视频 403、字幕 404、文本渲染失败，确认仅能归因的字幕故障执行字幕回退。
8. 本地文件撤销授权/移除文件后重试；检查错误提示、锁定控制和画中画，不显示地址或凭据。

本轮不构建 APK、不部署、不推送；真机播放和真实服务结果不由 JVM 测试替代。
