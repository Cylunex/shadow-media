# Novel 新接口适配与书库体验

## 范围与依据

仅修改 Shadow Media。对照本机 Shadow Novel `54f5780`，重点核对 `521757d` 的目录与书架接口、
`2cff091` 的通用契约和 `54f5780` 的书源能力。Novel 远程拉取因当前凭据不可用未完成；
这里的“最新”指上述本机版本，不声称验证过远端更新。服务端源码和运行数据没有修改。

## 新接口落地

- `works` 与 `navigation` 同时携带 `has_updates=true`，显示 `counts.updates`。
  关闭快捷条件时移除参数，不发 `has_updates=false`，以恢复包含全部作品的书架。
- 分区“全部”从 `filter_link` 提取白名单内的本机查询参数，保留重复分类、题材、排除题材、
  匹配方式、可用性和最低热度。不会访问该链接或把服务地址写入缓存。
  缓存没有链接时保留已有分区回退；热门分区正确包含 `min_popularity=0`。
- 详情目录和原生 Novel 阅读器复用 `NovelContentsPanel`，请求固定版本的
  `contents?version_id=...&q=...&order=asc|desc&offset=...&limit=100`。
  搜索覆盖服务端整份目录；搜索与反转顺序回到第一页；当前章定位清除搜索、恢复正序。
- 使用服务端 `next_offset`，显式 null 即终页；旧响应缺少该字段时才依据条目数回退。
  页码对应过滤和排序后的结果，卷标题仍保留但不可点击。`latest` 用于“读末章”，不将最后一条搜索结果当作末章。
- 阅读器断网时可搜索所有本机已下载窗口中的标题，去重、排序并明确显示范围。
  该回退不显示“读末章”，也不把稀疏下载误认为完整目录。已有服务响应缓存另有缓存提示。
- 目录浏览、搜索、排序和翻页仅读元数据，不获取正文、不改阅读进度。
  选章沿用原有按需获取和跳转历史；实际打开失败时原正文和进度仍由既有阅读器保留。

## 界面与交互

- 书城：标题、搜索、分类/完本/热门/作家四入口、续读卡片和横向书籍分区。
  续读进度明确标为“本章已读”，不冒充全书比例。
- 作品列表与书架：自适应封面网格、列表模式、更新章数标记、可读/完结/在读快捷条件、
  可单独移除的筛选标签、排序、空状态和分页加载。书架/历史提供直接阅读按钮。
- 文字封面根据书名选择稳定配色，增加书脊与衬线标题；深浅色使用主题对应的前景色。
- 搜索支持键盘搜索键；清除关键词同时清除服务端搜索条件。更改筛选回到列表开头。
  详情返回恢复搜索词及筛选条件；重复应用相同条件不会清空列表。
- 目录支持正倒序、当前章、页码跳转、首页/末页、刷新和末章。
  工具入口集中到面板，避免顶部刷新按钮无效果。
- 详情版本状态改为中文。仅资料作品保持不可阅读；在线书源搜索沿用既有服务端能力校验。

## 验证

使用原创书名和目录数据进行 MockWebServer、Robolectric 和 Compose 交互回归。
执行以下任务，不生成 APK：

```sh
./gradlew :core:library:testDebugUnitTest :experience:reading:testDebugUnitTest \
  :app:testDebugUnitTest :app:lintDebug :experience:reading:lintDebug \
  :experience:reading:compileDebugAndroidTestKotlin
```

新增 14 项测试覆盖请求子路径/编码/版本与只读语义、显式终页、搜索排序后的定位、稀疏离线目录、
更新筛选语义、分区筛选一致性，以及首页搜索、书架视图/排序/筛选、可读状态、目录操作。
使用 `NATIVE_READER_SCREENSHOTS` 导出原生绘制截图，检查浅色首页、深色书架、320dp 书架和目录。
另验证 640dp 横屏中只剩 240dp 高度时，目录搜索、页码输入和翻页仍可操作。
三个模块合计 163 项测试：159 项通过、4 项依赖外部环境的既有测试跳过；编译与 Lint 无错误。

常规测试不含真实服务正文、实际登录与真机触摸验收。需要外部环境的既有测试按条件跳过，
不计作通过；Lint 的既有依赖更新和播放/TV 警告不属于本轮功能变更。
未部署、未构建安装包，也未增加书源执行器、整本批量下载或后台听书控制。
