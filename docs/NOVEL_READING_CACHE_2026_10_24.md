# Novel 阅读换源与提前缓存（2026-10-24）

本轮补齐阅读页内换源、目录缓存、本机全本/范围下载及滚动提前预取。功能按固定的连接、作品、目录版本隔离；正在阅读的正文和待同步位置独立于后台下载。

## 阅读中的换源

- Novel 阅读菜单增加“书源”，TXT 保持现有菜单。
- 在阅读页选择已有来源/版本，可续读该版本，或从其目录选择章节。当前章标题在目标目录中唯一匹配时提供“接着读当前章”，由读者明确选择；不按章节序号猜测。
- 直接搜索其他书源，统一收录时指定当前作品 `work_id`，等待固定目录版本后选章。不自动创建同名新作品；关联冲突按服务端错误显示。
- 可以检查当前书源的目录更新，获取新版本后由读者选择，当前阅读不会被后台更新切走。
- 目录搜索/来源选择不写阅读进度。真正换源后的用户移动沿用原子 ProgressWriter、冻结请求、幂等回执和冲突选择规则。
- 归并后的规范作品 ID 由详情接口证明，阅读包再与清单核对；旧包/旧请求的进度作用域保留原作品 ID，避免改变旧离线请求的幂等命名空间。

## 提前缓存与本机下载

### 自动预取

读取当前三章窗口后立即启动独立的内容缓存，不再等到窗口末尾。每次显示新章节都补足后面三章；已在本机的章节直接复用。预取只保存不可变 EPUB 窗口，不创建阅读会话、不种入 0% 位置、不发送进度 PUT，也不持有阅读会话锁。一次失败会保留其余可下载章节和当前画面；每次章节显示最多尝试三轮。

预取使用资源调度器的相邻内容优先级；批量下载使用离线优先级。窗口导入只短暂串行，HTTP 不占数据库事务。相同窗口共享有限数量的锁，避免重复导入和无限增长的锁表。

预取清单的已知目录节点还会保存到有容量上限的目录页缓存中。离线翻章只跨过已知的卷标题，不会把缺少的正文当作卷标题跳过；完整下载的目录另行持久保留。

### 目录中的缓存与下载

“缓存与下载”打开可滚动面板，支持：

- 缓存完整固定版本目录，离线按全目录查找；下载标记来自本机文件，未下载章节保持可辨认。
- 下载全本、从当前开始缓存 50 节、自选起止目录序号。卷标题自动跳过。
- Wi-Fi 限制、下载数量、失败数量、暂停、继续及重试未完成章节。后台任务使用已有 dataSync 前台服务能力，离开阅读页后继续执行。
- 任务调度由 WorkManager 持久保存，状态和操作代号使用应用私有目录中的原子 JSON 文件。新一轮操作拒绝旧工作任务的晚到结果。

完整目录缓存独立于可淘汰的在线页面缓存。全本下载按 20 个目录节点分窗，重启后核对本机包 SHA-256 并跳过有效内容；单个源章节失败不会丢弃其他可读章节。损坏的本机副本可由校验通过的相同内容修复，定位身份不变。后台窗口不会逐一增加书架条目；Novel 离线列表按作品/版本合并展示，并优先使用实际阅读位置所属的包。

本机完成数量只在 EPUB 安装和映射校验通过后递增。所有目标章节下载完成且目录完整时才显示“全本已下载”；目录不完整或只选择部分范围时分别显示当前目录/所选目录完成，不代表连载作品已经完结。

## Novel 接口兼容

新增后端能力由独立 Novel 会话实现，提交 `f12afc60bf69fb569b48e276e07510365e53e81d`；契约见 Novel 的 `docs/media-integration.md`。

- 发现支持 `reading_cache_jobs` 时，本机下载按最多 20 个可读章节创建 `POST /works/{work_id}/cache-jobs`，轮询通用 Jobs 接口，记录任务 ID 和固定选择。任务重启可以续查原服务端任务。
- 逐一核对回执、任务 payload 的作品/版本/章节身份；服务端完成后仍下载并校验本机 EPUB。服务器缓存进度不会冒充本机离线进度。
- 本机暂停先保存状态、取消 WorkManager，再有界尝试取消当前服务器批次；网络断开时该批次至多 20 章，已下载内容保留。
- 旧服务没有能力标志时，继续按预算 `GET /chapters/{id}` 再下载窗口，因此换源和本机下载可直接使用既有服务。新后端代码尚需另行部署。
- 预取、缓存、下载都不强改 `expected_revision`。首次打开从未阅读的下载包才建立本机阅读状态；初始显示仍不写云端进度。
