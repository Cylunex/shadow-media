# Novel 阅读交互收敛（2026-11-02）

本轮针对 Media 内 Novel 的阅读与续读体验，不改服务端契约，不新增依赖。

## 改动

- 阅读始终保留系统状态栏的时间和电量。窗口与页面使用同一纸张底色，状态栏透明并关闭系统对比度蒙层；按日夜纸张切换图标明暗。正文避让状态栏，横屏避让侧边刘海，菜单开关不改变正文视口。原全屏选项改为明确的“隐藏底部系统导航（保留时间与电量）”。
- 阅读底部操作改为上一章、下一章，从目标章节开头阅读；正文手势仍按页翻动，向前跨章仍进入上一章末页。切章保留返回跳转前位置的能力，卷标题继续跳过。
- 正文解析保留最多四章，排版保留最多三章。后台对前后相邻可用章节提前解析、排版，窗口、正文版本、标题、尺寸或排版参数变化后使用新缓存键；修改纸张颜色不触发重排。预热不打开阅读会话、不写进度，退出页面释放排版缓存。
- 切章仍保持原有进度写入顺序。短于 220 ms 的加载不闪进度条，未下载章节仍需获取内容，不承诺冷加载无等待。
- 目录滚动定位只响应首次显示、搜索、分页、排序和主动点击当前章；缓存状态和目录刷新不抢滚动位置。
- 小说主页面合并重复标题栏，模块切换和通用设置移入单一顶部栏，工具入口保留在书库选项中。返回底部标签时立即恢复内容与位置，第一页在后台刷新；已翻页的列表保留已加载内容，由用户主动刷新。避免生命周期订阅时重放 ON_RESUME 导致额外阻塞请求。
- 新增“深羊皮纸”，提供更浓的暖黄底色与棕色纹理；原羊皮纸保留。原生 Canvas、设置预览与 EPUB 使用同一配色与纹理强度，日夜切换可恢复所选纸张。深色纸纹在默认及满强度下采样验证正文对比度，状态栏与菜单同步使用深纸底色。
- 阅读菜单使用纸面配色、较小圆角和轻微分隔阴影，打开菜单沿用触感设置。

## 验证与范围

执行 `:experience:reading:testDebugUnitTest` 与 `:app:testDebugUnitTest`，覆盖真实 Canvas 交互、Android 28 窗口状态、切章菜单、缓存排版复用及字体变更、后台目录更新后的滚动位置，以及慢响应时书架内容可用性。检查日夜菜单、横屏、窄屏和单标题栏截图。

最终结果：阅读模块 87 项（85 通过、2 跳过），应用模块 47 项全部通过，共 132 项通过。两项依赖外部输入的阅读集成用例保持跳过。尝试补测 Android 35 时，Robolectric 平台依赖下载遇到 TLS 错误与 HTTP 429，未完成该平台验证。Robolectric 不绘制真实系统时钟、电量图标；系统栏在不同厂商真机上的最终观感与连续切章时延仍需设备验收。本轮未打包、安装或部署。
