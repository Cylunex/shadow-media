# 视频播放器功能核对与使用

本轮按 UnitPlayer 的功能清单补齐 Shadow Media 的普通视频体验，继续使用 Kotlin、Jetpack Compose 和 Media3。应用名称与现有 Emby、阅读、音频入口保持一致。

| 功能 | 核对结果与入口 |
| --- | --- |
| 左右滑调进度 | 新增，画面中央横滑预览目标位置，松手后跳转；不可拖动的直播提示原因 |
| 左侧亮度、右侧音量 | 新增，画面中央区域上下滑；亮度仅影响当前窗口，离开播放器恢复原值 |
| 双击快退/快进、长按 2 倍速 | 新增，两侧双击跳转 10 秒；长按临时 2 倍速，松开、取消或离开后恢复原速度 |
| 手机视频、添加文件夹 | 新增，「来源 → 本机视频与链接」支持扫描手机、系统文件选择器、递归导入文件夹；保存 URI 授权与索引，不复制或修改视频 |
| 继续观看 | 原有 Room 历史扩展到本机视频和视频链接；每 5 秒、后台暂停与退出时保存位置，可从本机视频入口或统一继续页恢复 |
| WebDAV 串流 | 已有，同时保留 OpenList、SMB 与独立凭据隔离 |
| 自动发现局域网服务器 | 新增，打开网络媒体库自动发现 15 秒，可重新发现；广播的 WebDAV、WebDAVS、HTTP、HTTPS 服务可填入添加表单 |
| 视频链接、m3u8 | 新增单条链接输入并播放；沿用 Media3 HLS 播放与直播订阅功能 |
| 同名外挂字幕 | 新增，本机已授权文件夹与普通网络视频自动匹配 SRT / ASS / VTT；支持 `影片.zh.srt` 等语言后缀；网络字幕发现失败不阻止视频播放；确认故障属于外挂字幕时移除字幕并重试视频 |
| 音轨与字幕轨切换 | 已有 Emby 与 ISO 轨道选择；新增统一普通视频设置面板，可直接选择轨道、关闭字幕、调整速度，以及手动选择本机字幕 |
| 字幕显示 | 新增 SubtitleView 与 CueGroup 监听，按视频比例显示文字与位图字幕；原 Compose ContentFrame 仅负责视频画面 |
| 画中画 | 已有自动进入；新增普通外部视频的手动入口，进入后隐藏操作层，睡眠定时继续运行 |
| 睡眠定时 | 新增视频端关闭 / 15 / 30 / 60 分钟，使用单调时钟；到期暂停，返回前台不会因自动恢复重新播放 |
| 锁定控制 | 新增，屏蔽触摸手势、控件及 Feed 切换，保留解锁按钮；返回键先解锁 |
| 耳机与蓝牙按键 | Emby 已有 MediaSession、音频焦点与拔耳机暂停；本机/外部视频新增独立 MediaSession 与媒体元数据，支持系统播放、暂停与 Seek 命令 |
| 断网恢复与原位重试 | 普通网络视频对明确的网络/临时 HTTP 错误最多自动重试两次，断网等待连接；暂停与后台暂缓恢复；本机/网络视频均可从当前位置手动重试；Emby 重新解析保留当前进度与暂停状态 |

## 使用范围

- Android 13+ 按需申请视频读取权限，Android 14+ 支持只授权部分视频。系统文件选择器和文件夹导入不要求全盘权限。
- Android 的单个视频 URI 授权不自动授予同目录字幕访问权。需要自动加载同目录字幕时，添加整个文件夹；仅选择视频时，可在「播放设置 → 选择外挂字幕」中添加字幕。
- 文件夹刷新保留授权失效目录的旧索引并提示重新授权；移除文件夹仅移除索引，不删除原文件。深度上限 32、目录数上限 10,000，超限可选择较小子目录。
- 局域网发现使用 DNS-SD，不进行全网段端口扫描。设备必须与手机在可接收服务广播的网络中；未广播服务的 NAS/电脑仍需手动添加。普通 HTTP 服务不一定是 WebDAV，需填写实际 DAV 路径与账号后验证连接。
- 新手势和定时适用于 Media3 普通视频。本轮没有扩展 libmpv 光盘镜像手势；ISO 原有章节、音轨、字幕与续播功能继续使用其专用控件。
- Feed 的画面中央区域用于播放手势；上下刷片可从预留的顶部或底部区域操作，也可使用遥控方向键。锁定时禁止切换。
- 睡眠定时属于当前播放器会话；退出播放页结束定时。暂停状态会被正常保留，手动暂停的视频不会因为前后台切换而自动播放。
- 恢复错误提示按网络、权限、资源、格式和解码分类；字幕仅在能归因于其请求或文本渲染的故障时移除并回退。次数约束、ISO/音频/SMB 边界与真机清单见 [播放恢复方案](RESEARCH_AND_PLAYBACK_RECOVERY_2026_10_15.md)。

## 验证

自动验证涵盖应用 Kotlin 编译、核心与应用单元测试，以及 Android lint。新增测试检查字幕匹配和格式、Seek 边界、本机链接持久化、无存储授权刷新、并发导入不丢条目、分页搜索及无效地址拒绝。

尚需真机验收：

1. 选择带同名 SRT、ASS、VTT 的目录，递归扫描后播放并切换、关闭字幕；试验独立选择视频后手动添加字幕。
2. Android 13+ 全量授权、Android 14+ 部分授权、拒绝扫描权限后使用系统选择器；重启应用后继续播放。
3. 横竖屏分别测试横滑、左右纵滑、双击、长按与松手；从 1.5 倍速长按后恢复 1.5 倍速。
4. 锁定后点击原控件、刷片、按返回解锁；测试耳机拔出暂停、蓝牙播放/暂停。
5. 连接广播 WebDAV 服务的局域网，确认发现、填入、认证、Range 播放、字幕与续播；无广播服务仍可手动添加。
6. 播放 m3u8 直播，进入和退出画中画；测试定时到期暂停，并确保回到前台不会自动续播。

实现参考：[Android 服务发现](https://developer.android.com/develop/connectivity/wifi/use-nsd)、[部分视频授权](https://developer.android.com/about/versions/14/changes/partial-photo-video-access)、[Media3 Player](https://github.com/androidx/media/blob/1.11.0/libraries/ui_compose_material3/src/main/java/androidx/media3/ui/compose/material3/Player.kt)、[ContentFrame](https://github.com/androidx/media/blob/1.11.0/libraries/ui_compose/src/main/java/androidx/media3/ui/compose/ContentFrame.kt)。
