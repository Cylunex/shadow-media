# 模块导航与黑白界面

日期：2026-10-28。适用于 Android 开发分支；本轮不发布服务、不构建安装包。

## 设计结论

将影视、小说、音乐、漫画、听书、直播作为独立内容空间。左上角显示当前模块及下拉箭头，切换时同步替换页面与底部导航，避免所有模块入口长期占据同一屏幕。底部菜单按已有功能组织，不统一凑成四项或五项。

| 模块 | 底部导航 | 页面和操作归属 |
| --- | --- | --- |
| 影视 | 首页、媒体库、影视仓 | 首页提供续播和推荐；媒体库连接私人影视库、网络存储、本机视频；影视仓沿用订阅浏览 |
| 小说 | 书架、书城、发现、书源 | 个人书架；书城推荐与搜索；榜单、主题书单、作家、分类；在线书源检索与管理 |
| 音乐 | 音乐库、歌单 | 歌曲、专辑、艺人、目录、最近和收藏是库内筛选；歌单是单独页面，进入歌曲后可返回全部歌单 |
| 漫画 | 书架、漫画库 | 本机与已加入作品；Komga / OPDS 目录 |
| 听书 | 书架、有声库 | 已加入有声书和续听；Audiobookshelf 目录与音轨 |
| 直播 | 无底部导航 | 单一频道入口，进入订阅后使用现有分组、搜索、收藏与节目单 |

右上角工具面板提供当前模块的连接或导入入口。通用设置放在模块下拉和工具面板中。跨模块历史、下载中心标注“所有模块”，不伪装成局部列表。小说页的历史、离线、本机书架、切换服务和管理工具收进页内“书库选项”。书架和来源浏览保留各自用途，不给低频设置新增底部菜单。

本机小说入口保留在小说工具与书库选项中；在线小说服务书架和本机 EPUB/TXT 书架目前仍是两个页面。漫画库与有声库使用现有目录接口，不新增没有服务端支持的推荐或排行榜。

## 参考方案与取舍

- 用户提供的三张截图：采用左上角模块下拉、封面优先、标题最多两行和底部细线选中标记。缩减顶部常驻图标，模块间统一主色。
- [Grok 官方产品](https://x.ai/grok)：按用户指定的黑白方向建立视觉方案。灰阶表面、字重、留白承担层次，不复制品牌图标或页面资产。
- [Mihon 入门文档](https://mihon.app/docs/guides/getting-started)：官方流程区分来源浏览、搜索与加入个人书库。Media 据此明确“我的书架”和“目录入口”，漫画混合 OPDS 目录只展示本模块可用内容，保留文件夹导航。
- [Metrolist](https://github.com/MetrolistGroup/Metrolist)：官方列出了音乐库、本地歌单、歌单导入与队列排序，并提供 Light / Dark / Black 主题。Media 沿用已有音乐能力，将音乐库与歌单分开，迷你播放条独立于底部导航；不引入其在线音乐平台和动态配色。
- [Read You](https://github.com/ReadYouApp/ReadYou)：作为原生 Compose / Material You 阅读应用的组件参考。Media 继续使用原生控件、主题语义和可访问标签，不把整个页面改成 WebView，也不采用动态彩色主题。
- [ESO](https://github.com/mabDc/eso)：全媒介阅读器作为多内容类型组织的对照。Media 的影视、直播、小说和音频已有不同业务流程，因此选择模块专属页面和菜单，不使用同一列表包办所有类型。

以上是信息架构与产品能力对照，不引入第三方项目代码或美术资产。菜单数量是结合当前仓库功能做出的设计判断。

## 视觉规范

- 深色背景 `#101010`，基础表面 `#171717`，主文字 `#F4F4F4`；浅色背景 `#FAFAFA`，主文字 `#171717`。所有 Material 表面、容器及逆色都显式定义为灰阶，避免默认紫色或蓝色混入。
- 保留错误语义色和封面原图颜色。主按钮使用黑白对比；不按模块切换强调色。
- 移除动态发光背景、玻璃渐变和大面积品牌水印。常规卡片使用实色底与细边框。
- 模块标题 27sp，页内标题收敛字重；封面圆角 14dp；底部使用线性图标、文字和短横线共同表达选中态。
- 封面网格自适应：常见手机展示三列，窄屏减少列数。书架作品菜单覆盖于封面角落，标题使用完整宽度。
- 系统状态栏与导航栏图标亮暗跟随应用选择的主题。独立阅读器的纸色设置保持原有职责。

## 实现边界

`MediaModule` / `MediaDestination` 使用稳定枚举键保存当前模块和各模块最近菜单。非法或旧键回退到相应模块首页；不同模块的菜单键不能串用。模块页使用 `SaveableStateHolder` 保存可恢复 UI 状态；不承诺所有网络详情跨进程恢复。

小说底部页面在当前组合存续期间分别保存路由、查询、结果和返回栈；切换时取消旧请求，再恢复目标页面并重新获取内容，避免其他页面加入书架后仍显示旧列表。音乐歌单提供返回列表按钮与系统返回行为。切换模块保留后台音频服务，播放器仍使用现有全屏路径。

书架根据 BOOK / COMIC / AUDIOBOOK / MUSIC 分类；目录连接按服务类型过滤，混合 OPDS 再按叶子条目格式过滤。通用连接页可以管理全部目录。播放、阅读、导入、离线和来源接口沿用现有实现。

## 验证

使用 JDK 17 执行 `:app:testDebugUnitTest :app:lintDebug --offline`：41 项测试通过，Lint 无错误（39 项警告）。新增覆盖：模块菜单切换、直播单页导航、非法菜单恢复、混合目录隔离、小说底部切换后的详情返回栈、窄屏操作入口。复跑已有小说搜索与书库、分页和播放状态测试。

Robolectric Native Graphics 渲染 393dp 深色与 320dp 浅色截图，覆盖真实 Compose 导航和小说屏幕，数据由本地测试服务提供；它们是组件／页面测试截图，不是已安装 APK 的设备截图。

真机上的系统返回手势、横竖屏切换、遥控器焦点和真实服务连接仍需设备验收。未更改签名或部署配置。
