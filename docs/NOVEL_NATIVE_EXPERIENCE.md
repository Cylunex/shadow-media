# 小说原生书城与阅读交互

## 参考与落地

2026-10-21 查阅官方产品介绍、网站及开源项目：

| 参考 | 观察与本次实现 |
|---|---|
| [起点读书官方介绍](https://apps.apple.com/cn/app/id534174796)、[起点书单](https://book.qidian.com/booklist/) | 分类找书、主题合辑与继续阅读的衔接：保留书城分区，加入横向封面展示、近期书单预览和继续阅读入口。 |
| [番茄小说官方介绍](https://apps.apple.com/cn/app/id1468454200)、[番茄小说网](https://fanqienovel.com/) | 按分类、精选和榜单找书：以书城、书架、书单、排行作为四个主入口，分类、搜索、作家、历史与离线作为次级入口。 |
| [Legado](https://github.com/LegadoTeam/legado)、[Lumi 阅读器](https://github.com/legado-backup/legado-lumi)、[Readest](https://github.com/readest/readest) | 原生阅读、排版设置与手势分工的参考。继续沿用项目已有的 Legado 原生排版及 Readium EPUB 内核，本次没有复制其他项目代码或增加运行时依赖。 |

这些参考用于发现路径、信息层级和交互选择，界面使用现有 Shadow Material 3 主题。书籍、书单、排行、封面与写入操作全部使用 Novel API；服务端返回的网页链接不参与原生导航。没有嵌入 Novel 网站，也没有调用起点或番茄的私有接口。

## 书城、书单与作品

- 书城调用 `city/home`，保留热门、最近收录、完结可读、分类精选和换一本。每个分区以横向封面展示，更多按钮以原生筛选参数进入完整列表。
- `works?view=history&limit=1` 提供继续阅读，`booklists?limit=3` 提供近期主题书单。附属分区失败不遮挡正常书城。
- 书单支持封面拼图、数量与简介、成员、推荐语、成员排序、移除、编辑、软删除和恢复；从作品详情加入书单沿用既有接口。
- 作品详情显示封面和内容可用状态；只有资料、没有可读版本的作品不会显示可执行的开始阅读按钮。
- 封面统一请求配置来源内的 `works/{id}/cover`，共用 OIDC 刷新和同源重定向检查；不把服务端提供的任意图片 URL 交给公共图片加载器。响应限制 4 MiB，以最长边约 512 像素为目标采样，字节缓存限制 8 MiB 并按连接作用域隔离。没有封面或离线时显示文字封面。
- 返回榜单时保留来源、榜期与分类选择，恢复页面滚动状态。作品和列表仍使用服务端分页。

## 原生排行榜

| API | 客户端行为 |
|---|---|
| `GET rankings` | 显示已启用来源及其真实榜期、指标；来源之间不混排。 |
| `GET rankings/local` | 书库热榜、最近收录、完结可读、我的高分，支持分类筛选，只提供总榜。 |
| `GET rankings/{provider}/{key}` | 保留名次、原始指标、首次观测/变化、获取时间、错误和缓存状态；可分页。 |
| `POST rankings/{provider}/{key}/refresh`、`GET jobs/{id}` | 保留当前结果并更新，轮询有时限；超时提示稍后刷新。过期榜单尝试刷新，网络缓存和离线状态不触发后台刷新。 |
| `POST rankings/{provider}/{key}/collect` | 使用当前快照 `token` 与服务端 `index` 收录选定作品资料。409 后重新加载，等待用户重新选择，不自动收录新位置。 |
| `PATCH me/books/{id}` | 已匹配作品可加入书架、进入原生详情；未匹配作品可收录资料或原生搜索书库。 |
| `POST rankings/websites` | 原生表单添加来源名称、站点、页面类型及实际榜期地址；没有的榜期留空。 |

仅有资料的榜单条目不冒充可读正文。未提供的榜期禁用，书库热度保留“含本地估算”口径。外站翻页若发现快照改变，会重置为新榜单第一页，避免把两个快照的名次或收录位置混在一起。

实际服务域名继续由来源配置提供。榜单网站地址由用户在表单中提供并保存到 Novel 服务配置，仓库示例只使用占位地址。

## 阅读手势与 Android 返回

- 无弹层时系统返回直接退出阅读，中央菜单打开时同样退出；目录、设置等弹层先关闭，再次返回退出。原生 TXT/Novel 和 Readium EPUB 都注册生命周期内的 Android 返回回调。
- 菜单打开后点击正文空白可收起；菜单遮罩拦截正文触摸，不会边操作菜单边翻页。
- 横向拖拽跟手翻页，结合位移与速度判断完成；短距离快速滑动可以翻页，小幅抖动、反向回拖和取消事件不会误翻。一次手势锁定方向。
- 双指缩放和长按摘录占用当前触摸序列，结束时不再附带翻页或打开菜单。滚动模式取消触摸时保留当前可见位置。
- Android 报告的系统手势左右边缘让给系统返回；亮度调节从系统边缘之外的左侧区域触发，并从当前亮度开始。
- 字符锚点、离线章节、跨章获取和进度同步协议保持原逻辑。

## 验证范围

使用原创数据、MockWebServer、Robolectric 和真实 MotionEvent 验证榜期/来源隔离、快照切换、封面认证与格式、返回优先级、滑动/取消/菜单拦截和字符进度。完整 Gradle 测试、Lint 与验收源编译作为提交检查。

本次没有构建 APK 或部署服务器。真机系统返回手势、首次授权和真实外站榜单可用性仍需要设备与用户自有来源验收。
