# 阅读体验第二版实施记录

## 已实现

- Novel 同正文的 text_v1 字符锚点可以与原生字符定位互读。复用版本、章节及 SHA-256 正文哈希校验，保留旧定位回退和 8 KiB 上限。
- 原生长按从触点选择短句，拖动扩大或缩小范围，章内边缘停留扩展到相邻页；复制、摘录分开执行。摘录保存显示上限，失败保留文字，成功可撤销。
- 正文搜索默认只搜读到的位置之前，当前章后文也排除，前文从近到远显示。可勾选包括后文，点击结果预览后再到原文。
- 阅读设置按书保存差异，Novel 的不同缓存窗口使用同一作品设置。可跟随默认、设为默认。亮度和音量键等设备设置保存在设备默认值中。
- 左手点击热区镜像，中央保持菜单。滚动中轻点先刹停，系统取消亮度手势回滚。
- 听读增加上次中断句、逐句前后移动、语速、从此处听、回到正在听、定时及本章结束停止。浏览时可解除视口跟随，拔耳机暂停。
- EPUB 提供原书排版，启用后清除个人正文样式与纸张注入。
- 漫画模式按书保存，双页封面独占，切换模式保留当前物理页，单页加载失败可重试。

## 第二轮补齐

- 使用独立前台朗读服务、系统媒体会话与媒体通知持有播放。退出或销毁阅读 Activity 后继续朗读，通知与锁屏可暂停、继续、逐句切换和结束。耳机断开、失去音频焦点均暂停；显式继续才恢复。
- 系统离线音色可选择，逐句高亮与播点独立于浏览视口。小说、TXT 自动接章；EPUB 按正文元素逐句读，保留句子上下文。定时与章末停止由服务持有。
- 条漫改为连续纵向列表，图片按宽度和实际比例布局，保留分块解码。保存物理页及页内位置，恢复、跳页、书签和模式切换均走同一位置。单页失败原位重试；目录中间的缺页不会被自动略过。
- EPUB 脚注就近打开可关闭弹层，跨资源脚注只读取同源书籍资源。插图支持放大、双指缩放与平移；关闭弹层归还原文焦点，主阅读位置不变化。无法解析的脚注保留原链接处理。
- 正文菜单统一为目录、排版、听读、更多。目录可进入书签与摘录，支持全部、书签、摘录筛选；保留原 EPUB 笔记编辑入口。
- 首次进入显示手势说明，更多内可再次查看。左手热区切换时明确提示方向。
- 搜索关键词、范围、结果和滚动位置在面板关闭后保留。Activity 重建保存关键词、范围和滚动位置，并重建搜索结果。
- 原生选区增加手柄触控范围、空白处取消、章内跨页扩展、从此处听和读屏选择当前段落。章名与正文空白区域长按不再命中不相干文字。
- 修正封面独占双页后偶数页数作品的“已读完”判定，最后一张独立页须实际显示才完成。
- 播放服务与当前阅读器共享同一进度写入会话，界面打开、跟随播放及后台接章不会互相作废写入会话。

## 验证结果与范围

- 阅读模块 93 项、书库模块 139 项，共 232 项。228 通过，4 项可选外部样本跳过。
- 覆盖无 Activity 跨章朗读与进度持久化、媒体通知与停止命令、逐句边界、封面双页完成判定、字符锚点互读、搜索范围和设置继承。
- 阅读模块 lint 无错误。保留依赖版本提示及 Android API 弃用等警告。
- 整 App Kotlin 编译在隔离工作区通过。隔离验证基于当前已提交版本与本次全部阅读改动，避免混入另一个会话正在修改的 MDC 页面和 Provider。
- Chrome 390px 检查了实际 EPUB 预览脚本，脚注、插图开合后地址和原文位置不变。Novel 的窄屏、宽屏阅读与旧入口回归见服务端实施记录。
- 当前未连接 Android 设备。厂商 TTS、真实锁屏媒体按键、触控手感、两台真机互读和实际弱网时延属于设备验收范围；自动化结果不替代这些检查。
