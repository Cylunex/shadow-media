# Shadow MDC 片库

影视媒体库和设置页均可打开 Shadow MDC。添加服务地址与移动端访问令牌，通过连接测试后保存到独立的 Android Keystore 加密存储。支持带路径前缀的服务地址。服务端必须提供 `/api/media/v1` 契约。

片库支持分页、番号/标题/演员检索、封面与简介。作品详情的播放按钮解析到精确 Emby 条目，以 Media 已保存的同服务器账号读取详情和续播，再进入现有原生播放链。原始 Emby 管理密钥不会传给手机。连接多个同服务器账号时使用当前选中的账号，否则先在 Emby 服务页选择。退出播放器返回原作品详情。

没有唯一自动匹配时，点「选择或更换 Emby 影片」检索并选择一次。关联存于 MDC，后续播放直接读取条目。多分片或多版本可更换 Emby 关联，在线版本从详情内选择。MDC 目录默认独立浏览，可在连接中选择加入聚合搜索。远端字幕和线路、Emby 播放进度继续由既有 Emby 播放链处理。

自动回归覆盖前缀、凭据、分页及精确播放目标，并检查重定向不会外发 MDC 令牌。真机和真实 Emby 播放联调待上线前执行。

## 分类目录和在线点播增量

MDC 页面增加演员入口、发行年、机构和标签筛选。查询使用统一 catalog 契约。
默认播放计划优先精确 Emby 条目，也支持已配置在线 VOD；多个在线候选在详情内选择。
详情中「在线版本与线路」可直接查询在线候选。在线历史按作品和版本分开，
Emby 继续使用实际账号进度。在线流目前复用已有外部原生播放器，已接入同版本地址重解与一次自动恢复。真实设备的首帧、Seek 与网络切换交由用户验收。


演员、题材、形式、地区、年份、机构与标签可组合浏览，片单保持服务端手工顺序。
筛选区可收起，年代可下钻到发行年份；演员页展示简介、别名、本库作品年份与合作机构。打开作品详情后返回保留列表位置。
可在连接编辑页填写 Web 片单页提供的片单标识，跨客户端使用同一偏好空间。
连接及凭据依旧加密保存，头像通过当前 MDC origin 的带令牌接口加载。
无后缀 HLS 使用显式 MIME，已确认 HTTP 视频复用外部原生播放器。

MDC 来源已注册到统一来源注册表，应用重启后的继续观看也可按原连接及版本重新解析。
连接默认独立浏览，可在编辑连接时选择“加入聚合搜索”。
