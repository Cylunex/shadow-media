# Shadow MDC 片库

影视媒体库和设置页均可打开 Shadow MDC。已登录 Novel 统一账号后，Media 从已认证的 `/api/v1/services` 发现同源 MDC 服务，自动显示「已共用统一账号」。无需再填服务地址、登录或复制访问令牌。网关需启用下述服务桥接；未启用的旧服务不会自动出现。

作品、演员、片单和封面引用 Novel 加密仓中的同一会话，每次请求复用自动续期，401 只强制刷新一次。退出或移除 Novel 账号后，MDC 不再使用该会话；失效时回到 Novel 重新登录。手机不另存 Refresh Token 或服务端 MDC 令牌。服务入口严格限制为已登录 Novel 根路径下的 `services/mdc/`，不接受其他主机或路径。

独立 MDC 仍可手动添加服务地址与移动端令牌，通过连接测试后保存到独立的 Android Keystore 加密存储。支持带路径前缀的服务地址。服务端必须提供 `/api/media/v1` 契约。

统一服务桥接由 Novel Edge 提供：`edge_mdc_upstream` 指定固定 MDC 根地址，`edge_mdc_token_file` 指向受限令牌文件；手机只访问 `/services/mdc/api/media/v1/`。网关先校验已有 OIDC 身份及账号白名单，再将凭据替换为仅服务端持有的 MDC 移动令牌。管理 API 不在桥接范围。部署配置和秘密均置于仓库外。

片库支持分页、番号/标题/演员检索、封面与简介。作品详情的播放按钮解析到精确 Emby 条目，以 Media 已保存的同服务器账号读取详情和续播，再进入现有原生播放链。原始 Emby 管理密钥不会传给手机。连接多个同服务器账号时使用当前选中的账号，否则先在 Emby 服务页选择。退出播放器返回原作品详情。

没有唯一自动匹配时，点「选择或更换 Emby 影片」检索并选择一次。关联存于 MDC，后续播放直接读取条目。多分片或多版本可更换 Emby 关联，在线版本从详情内选择。MDC 目录默认独立浏览，可在连接中选择加入聚合搜索。远端字幕和线路、Emby 播放进度继续由既有 Emby 播放链处理。

自动回归覆盖前缀、凭据、分页及精确播放目标，并检查重定向不会外发 MDC 令牌。真机和真实 Emby 播放联调待上线前执行。

## 分类目录和在线点播增量

MDC 页面增加演员入口、发行年、制作机构、厂牌、发布平台、作品系列和标签筛选。查询使用统一 catalog 契约；系列归属与机构制作、发行署名分开，演员页也分别显示合作机构和参演系列。
标签筛选按服务端 `parent_id` 逐层浏览，分组与具体标签都是树节点。「下级标签」仅切换浏览层级，点击节点筛选自身及所有后代；计数直接使用服务端的去重作品数。面包屑可返回上级，已选标签可随时清除；旧服务的平铺标签仍可使用。
默认播放计划优先精确 Emby 条目，也支持已配置在线 VOD；多个在线候选在详情内选择。
详情中「在线版本与线路」可直接查询在线候选。独立线路从原连接、作品和版本对应的本机历史续播，沿用旧版已写入的历史标识。可从 MDC 作品详情恢复；跨模块首页和继续列表不会推荐独立线路。
Emby 继续使用实际账号进度。在线流目前复用已有外部原生播放器，已接入同版本地址重解与一次自动恢复。真实设备的首帧、Seek 与网络切换交由用户验收。


演员、题材、形式、地区、年份、机构与标签可组合浏览，片单保持服务端手工顺序。
筛选区可收起，年代可下钻到发行年份；演员页展示简介、别名、本库作品年份与合作机构。打开作品详情后返回保留列表位置。
可在连接编辑页填写 Web 片单页提供的片单标识，跨客户端使用同一偏好空间。
连接及凭据依旧加密保存，头像通过当前 MDC origin 的带令牌接口加载。
无后缀 HLS 使用显式 MIME，已确认 HTTP 视频复用外部原生播放器。

MDC 来源已注册到统一来源注册表，应用重启后的继续观看也可按原连接及版本重新解析。
连接默认独立浏览，可在编辑连接时选择“加入聚合搜索”。
