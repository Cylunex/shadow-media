# 书架、书源、发现和换源排版优化

## 书架问题

- 选择排序只写偏好、入口却新建默认查询，导致重新进入后显示最近收录。现在在请求书架数据前恢复排序，按连接、书架分组和未分组分别保存，兼容旧的排序偏好。
- 覆盖底部页面切换、移除后重新创建页面、筛选重置、分组切换和阅读返回。发现首页的“热门”等显式筛选继续使用栏目自己的排序，不被书架偏好覆盖。
- 网格固定三列，保留一列列表切换。回归直接检查前三本横排、第四本进入下一排。

## 换源时字体和排版变化

原生阅读在每次打开章节、缓存窗口或其他书源时重新读取设置，导致阅读中继承的默认值可能被其他页面的新默认值替换。现在以连接与作品为稳定身份，同一阅读会话换源/切章沿用当前完整设置；版本和窗口不参与排版身份。

切到另一部书、重新打开阅读器或明确选择“跟随默认”才加载相应设置。先完成正文准备再绑定设置，准备失败时保留当前显示和排版。字号、字体、行距、段距、边距、纸张等走同一份设置，不逐项复制。

## 更多细节

- 发现书源增加名称查找与本机置顶，按连接保存；不改动服务端的搜索优先级。
- 书源选择器增加有效命中排序，并显示搜索、目录和正文各自的验证状态，继续使用真实统计和当前规则的校验结果。
- 发现内容的返回栏目、上一页、下一页和刷新放在结果列表外；查询中禁用重复请求。
- 发现首页可刷新、展开全部栏目，栏目“更多”使用服务端筛选参数进入对应书城列表。
- 排行榜按连接记住来源、榜期、栏目和分类，来源较多时可查找来源或栏目。
- 排行榜“找可读书源”按书名自动开始查询，避免把作者拼入关键词导致漏搜；保留榜单中作者显示与已有结果分组。
- 榜单中的“已在书架”使用 Novel 实际状态，已删除作品的来源映射不会误显示为活动书目。
